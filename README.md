# Integrative transcriptomic dynamics in HPV-driven neoplasia and cervical cancer progression

Code, commented notebook and result tables for the manuscript of the same title (de Oliveira et al.). Repository URL: https://github.com/micael-oliveira-ufam/Transcriptomics_HPV

## What is here
| Path | Content |
|---|---|
| `notebook/Lab_notebook_figures_reproducible.ipynb` | Commented lab notebook (R kernel, English) that reproduces every figure. Output cells are empty (recipe). |
| `code/cells/c01...c12*.R` | The scripts the notebook is built from: setup, GSE63514 (c02-c05), TCGA-CESC expression (c06-c08), clinical descriptors and annotated heatmap (c09), survival (c10), HM450 methylation (c11), probe-rule sensitivity (c12). |

## Figure numbering
Scripts write `Fig2_*`, `Fig3_*`, `Fig4_*`, `Fig6_*`, `Fig7_*`, `Fig8_*`, `Fig9_*`; in the manuscript these are Fig. 1 (volcano, GSE63514), Fig. 2 (GO Biological Process), Fig. 3 (18-transcript panel along progression), Fig. 4 (TCGA-CESC volcano, `Fig6_*`), Fig. 5 (annotated TCGA-CESC heatmap, `Fig7_*`), Fig. 6 (survival, `Fig8_*`) and Fig. 7 (methylation, `Fig9_*`). `Fig5_heatmap_TCGA_CESC` is an earlier unannotated heatmap not used in the manuscript.

## Data
* GSE63514 (GEO; Affymetrix U133 Plus 2.0, GPL570): downloaded with GEOquery and cached in `data/` (the group labels are parsed from the sample characteristics).
* TCGA-CESC (GDC; STAR - Counts, `tpm_unstrand`): downloaded with TCGAbiolinks (309 files, about 1.3 GB) into `data/GDCdata`.
* TCGA-CESC DNA methylation (GDC; Illumina HM450, SeSAMe level-3 beta values): 312 files, >1 h download; the probe annotation (GPL13534) comes from GEO. All data in this repository concern cervical samples only.
`data/` is not versioned.

## How to run
1. Install R (4.6.1 was used) and Bioconductor 3.23. The first cell of the notebook installs the packages.
2. Open R in the repository root and run `source("code/run_all.R")`, or execute the notebook cells in order.
3. Outputs go to `results/`. Compare `results/tables/numbers_logged_all.csv` with the reference file in this repository.

Notes: `sink()` interferes with GEOquery and GDC downloads, so the runners start logging only after data loading. A fixed seed (2026) is set. Analysis choices that matter: probe/gene collapsing by highest mean; removal of MT- and ribosomal-protein transcripts before all analyses (sensitivity analysis with them retained is reported); exact Wilcoxon test for TCGA tumour (n = 304) versus normal (n = 3).

Tested on macOS (arm64), R 4.6.1, Bioconductor 3.23. The notebook was not executed in a Jupyter kernel; the scripts were run in RStudio.
